🦆 다온 AI 튜터

찾아가는 학습클리닉 멘토를 위한 무료 수업 도우미 — 수업안·연습문제·정답 검산은 지금 바로, 대화형 AI는 무료 API 키를 연결하면 더 똑똑해져요.

키 없이도 기본 기능 전부 작동 대화 내용 서버 저장 없음 직접 작성한 시연 자료 · 공식 교과서 아님
로컬 모드 — 자료 검색·템플릿·정확 계산
학생
🧒 학생 모드 — 답 대신 힌트로 이끌어 줍니다. 13세 미만은 반드시 선생님·보호자와 함께 사용하세요. 이 모드에서는 대화·기록이 저장되지 않고, 힘든 이야기가 나오면 어른에게 말하라고 안내합니다.

이름·연락처 등 학생 개인정보는 입력하지 마세요. AI 연결 시 질문(과 사진)이 해당 외부 서비스로 전송됩니다.

수준별로 바꿔 보기

설명·지문·지시문을 붙여 넣으면 쉬운 말 · 보통 · 도전 세 수준으로 바꿔 줘요. 기초가 다른 아이들에게 같은 내용을 다르게 건넬 때 씁니다.

로컬 모드는 규칙 기반이라 쉬운 말 치환·문장 나누기 정도만 돼요. AI를 연결하면 훨씬 자연스러운 변환을 해 줍니다.

오늘의 멘토 활동일지

이 브라우저에서 오늘 한 활동(수업안·연습문제·오답 기록·AI 질문)을 모아 일지 초안을 만들어 줘요. 기록은 이 기기에만 저장되고, 지우면 영구 삭제됩니다.

무료·저렴 AI 연결하기

가장 쉬운 방법은 브라우저에서 직접 실행 — 설치·키·회원가입 없이 이 페이지 안에서 AI가 답합니다(첫 실행 때 모델을 한 번 받습니다). 더 빠르고 똑똑한 답변을 원하면 아래 무료 서비스의 API 키를 붙여 넣으세요. 키는 이 브라우저에만 저장되며 어디에도 업로드되지 않습니다. 한도·가격은 각 서비스 정책에 따라 바뀔 수 있습니다.

첫 실행 때 모델(수백MB)을 한 번 받아 두면 그다음부터 인터넷 없이도 작동해요. 답변은 내 컴퓨터가 직접 계산하므로 처음엔 몇 분 걸릴 수도 있지만, 외부로 나가는 내용은 전혀 없습니다.

📖 발급 방법·서비스 비교 가이드 열기
학생 이름·학교·연락처·진단 결과는 어떤 AI 서비스에도 보내지 마세요. 무료 티어는 서비스에 따라 입력이 모델 학습에 쓰일 수 있습니다 — 수업 자료 수준의 일반 질문만 보내는 것이 안전합니다. ('브라우저에서 직접 실행'은 외부 전송이 아예 없습니다.)

무엇을 할 수 있나요

  • 계산·검산 — 487+268, 85÷4, 3/4+1/8 처럼 입력하면 브라우저 안의 정확 계산기가 분수·몫·나머지까지 답합니다. AI가 아니라 확정된 계산이라 틀리지 않아요.
  • 수업안·연습문제 — 학년·주제·시간을 고르면 도입–탐구–연습–정리 흐름과 문제 3개, 정답·해설·힌트·출처를 만듭니다.
  • 자료 검색 — 직접 작성한 지도 자료에서 근거를 찾아 답합니다. 자료에 없는 건 없다고 말합니다.
  • 학생(힌트) 모드 — 챗봇 상단의 '학생'을 누르면 정답 대신 힌트 단계로 이끌고, 기록을 남기지 않습니다. 학생이 직접 쓸 때 켜세요.
  • 학생 별칭·오답 노트 — 실명 대신 별칭으로 학생을 고르고, 문제의 ✓/✗ 버튼으로 맞힘·틀림을 기록합니다. 이 기기에만 저장됩니다.
  • 수준 맞춤 — 설명문을 쉬운 말·보통·도전 3단계로 바꿉니다.
  • 활동일지 — 오늘 한 활동을 모아 일지 초안을 만들어 줍니다.
  • 사진 문제 — 📷로 문제 사진을 올리면 AI가 읽고 힌트를 줍니다(Gemini·GitHub 무료 연결 시).
  • AI 대화(선택) — 무료 API를 연결하면 찾은 자료를 근거로 AI가 자연스럽게 풀어 설명합니다. 답변 아래 자동 점검(없는 출처·주의 표현·계산 검산)을 표시합니다.
  • 브라우저 직접 실행 — 🔑 연결 탭에서 '브라우저에서 직접 실행'을 고르면 설치·키 없이 이 페이지 안에서 AI가 돌아요. 외부 전송이 전혀 없고, 첫 실행 이후엔 오프라인에서도 됩니다(답변이 느리고 수준이 얕아요).

정직하게 알려드리는 한계

  • 자료는 이 페이지 안의 직접 작성 시연 자료뿐입니다. 교과서 쪽수, 동영상 링크, 다른 학교 기록 같은 건 물어봐도 없다고 답합니다.
  • 무료 AI는 하루 사용 한도가 있습니다. 한도가 차면 자동으로 로컬 모드 답변으로 돌아갑니다.
  • AI 답변은 미검증 초안입니다. 수업 전에 개념·수치·난이도를 멘토가 직접 확인하세요.
