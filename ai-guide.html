무료·저렴 AI 활용 가이드

모델을 직접 만들지 않아도 됩니다. 이미 만들어진 세계적 AI를 API(열쇠 한 개)로 빌려 쓰는 방법 — 무료 티어부터 100만 토큰 수백 원짜리 초저가까지, 학습멘토 현장 기준으로 정리했습니다. 작성: 2026-10 · 각 서비스 정책은 바뀔 수 있으니 발급 전 공식 안내를 한 번 더 확인하세요.

한눈에 보는 결론

  • 직접 AI 모델 만들기는 비추천. 데이터 수집·GPU 비용·품질 검증이 필요하고, 8GB 맥북에서 돌린 소형 모델조차 한국어 지시 준수 실험에서 통과하지 못했습니다.
  • 정답은 "무료 API 빌려 쓰기". 구글 Gemini 무료 티어, Groq 무료 티어, GitHub Models 무료 제공분이면 멘토 수업 준비 용도는 충분히 커버됩니다.
  • 더 쓰고 싶으면 초저가 유료. DeepSeek·Gemini Flash-Lite 유료는 100만 토큰에 수백 원 — 한 달 수업 준비용으로 커피 한 잔 값 미만입니다.
  • 개인정보는 절대 API로 보내지 않기. 학생 이름·학교·진단 결과는 어떤 서비스에도 넣지 않습니다. 수업 자료 수준의 일반 질문만 보내세요.
바로 써보고 싶다면 → 다온 AI 튜터를 열고 🔑 무료 AI 연결 탭에서 키 하나만 넣으면 됩니다.

왜 직접 AI 모델 만들기는 어려운가

비용 벽

모델을 처음부터 학습(pre-training)하려면 GPU 수백~수천 대가 필요하고, 작게 미세조정(파인튜닝)해도 수백~수천 개의 검증된 한국어 교수법 데이터를 모아 정제해야 합니다.

품질 벽

우리 실험에서 Qwen3-1.7B(약 2GB)를 실제로 돌려 봤지만, 학생용 힌트 지시 5건을 모두 엄격 기준에 실패했고 성인용 지도 팁에서도 혼동되는 설명이 나왔습니다. "돌아간다"와 "쓸 수 있다"는 다릅니다.

검증 벽

수학 정답·출처를 AI가 지어내지 않는지 확인하는 별도 검증 장치가 필요합니다. 우리가 채택한 방법은 AI에게 정답을 맡기지 않고 규칙 기반 계산기+검색으로 정답을 만들고, AI는 설명 보조로만 두는 것입니다.

운영 벽

학교 PC에 7B급 모델을 24시간 돌리는 건 전기·발열·관리 부담이 큽니다. 무료 API는 서버 관리가 필요 없고 키 분실 시 재발급하면 끝입니다.

그래도 모델을 직접 굴려 보고 싶다면 → 아래 "내 컴퓨터에서 완전 무료" 절의 Ollama가 유일하게 현실적인 무료 자체 구동입니다. 단, 수업 정답·학생 대면에는 쓰지 말고 멘토 참고용 초안으로만 쓰세요.

내 컴퓨터에서 완전 무료 — Ollama

외부 전송 없이 내 PC가 AI 서버가 되는 방법입니다. 모델 파일만 한 번 내려받으면 인터넷 없이도 돌아갑니다.

  1. ollama.com에서 설치 → 터미널에 ollama run qwen3:4b (약 2.5GB 다운로드)
  2. 브라우저에서 쓰려면 환경변수 OLLAMA_ORIGINS=* 설정 후 재시작이 필요합니다
  3. 우리 챗봇의 "Ollama (내 컴퓨터)" 프리셋을 고르고 키 없이 저장하면 연결됩니다
주의: 4B 이하 소형 모델의 한국어 지도 품질은 무료 API의 70B·GPT급보다 떨어집니다(실험에서 확인). 정답·힌트에 쓰지 말고 멘토 브레인스토밍 참고용으로만 쓰세요.

발급 방법 — 3분이면 됩니다

Google Gemini (추천)

  1. aistudio.google.com/apikey 접속 → 구글 계정 로그인
  2. Create API key (API 키 만들기) 클릭 → 프로젝트는 자동 선택
  3. 생성된 키 복사 → 우리 챗봇의 🔑 탭에서 Gemini 선택 후 붙여넣기
  4. '연결 테스트'를 눌러 초록색 ✓ 확인

Groq (빠른 응답)

  1. console.groq.com/keys 접속 → 구글/이메일 로그인
  2. Create API Key → 이름은 아무거나 (예: mentor)
  3. 키 복사 → 챗봇 🔑 탭에서 Groq 선택 후 붙여넣기
  4. '연결 테스트'로 확인

GitHub Models (GitHub 계정 보유 시)

  1. github.com/settings/tokens → Generate new token
  2. 권한에 models:read만 체크해 생성
  3. 토큰 복사 → 챗봇 🔑 탭에서 GitHub Models 선택 후 붙여넣기

OpenRouter (여러 모델 비교)

  1. openrouter.ai/keys → 로그인 후 Create Key
  2. 모델 이름 끝이 :free인 모델만 무료입니다
  3. 키 붙여넣기 → 챗봇에서 모델명을 바꿔 다른 무료 모델도 시험 가능

다온 AI 튜터에 연결하는 법

  1. ai-tutor.html을 열고 🔑 무료 AI 연결 탭으로 갑니다
  2. 원하는 서비스 카드를 클릭 → 모델 이름이 자동으로 채워집니다
  3. 발급받은 키를 붙여넣고 저장 → 연결 테스트로 확인
  4. 상단 모드 바가 AI 모드로 바뀌면 끝. 챗봇 질문에 자료 검색 + AI 답변이 함께 나옵니다
  5. 한도가 차거나 끄고 싶으면 모드 바의 버튼으로 언제든 로컬 모드로 돌아갈 수 있습니다
키는 이 브라우저의 저장소에만 보관됩니다. 공용 PC라면 사용 후 🔑 탭의 '키 삭제'를 눌러 주세요.

꼭 지켜야 할 것

  • 개인정보: 학생 이름·연락처·학교·진단·상담 기록은 무료든 유료든 API로 보내지 않습니다. 무료 티어는 입력이 모델 학습에 쓰일 수 있습니다(Gemini 무료·Mistral 실험 플랜 등).
  • 정답의 주인은 규칙입니다: 수학 답·문제·출처는 AI가 아니라 우리 코드가 결정합니다. AI 답변은 '미검증 초안'으로 표시되니 수업 전에 반드시 멘토가 확인하세요.
  • 한도 예의: 무료 한도 초과 오류가 나면 반복 재시도하지 말고 다음 날을 기다리거나 다른 무료 키로 전환하세요. 자동 우회나 유료 경로 몰래 타기는 하지 않습니다.
  • 라이선스: 각 모델의 이용 조건(교육기관 사용, 결과물 배포)은 수시로 바뀝니다. 인쇄 배포·외부 공유 전 한 번 확인하세요.
