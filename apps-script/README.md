# 보강 신청 게시판 · 연결 안내

홈페이지의 **보강 신청** 탭은 기본적으로 *신청한 사람의 브라우저에만* 저장됩니다.
모든 강사가 **같은 목록을 함께 보는 게시판**으로 쓰려면 아래 순서대로 Google 시트를 연결해 주세요.
(약 5분 소요, 비용 없음)

---

## 1. 스프레드시트 만들기

1. <https://sheets.new> 를 열어 새 스프레드시트를 만듭니다.
2. 이름을 알아보기 쉽게 바꿉니다. 예) `학습클리닉 보강신청(2026-2학기)`
3. 시트는 그대로 두어도 됩니다. (`보강신청` 시트와 머리글은 자동으로 만들어집니다.)

## 2. Apps Script 붙여 넣기

1. 스프레드시트 상단 메뉴에서 **확장 프로그램 → Apps Script** 를 엽니다.
2. 편집기에 기본으로 들어 있는 `function myFunction() {...}` 를 **모두 지웁니다.**
3. 이 폴더의 [`Code.gs`](./Code.gs) 내용을 **전부 복사해서 붙여 넣습니다.**
4. 상단의 💾 (저장) 버튼을 누릅니다.

## 3. 웹 앱으로 배포

1. 오른쪽 위 **배포 → 새 배포** 를 클릭합니다.
2. 왼쪽 톱니바퀴(⚙) → **웹 앱** 을 선택합니다.
3. 아래처럼 설정합니다.

   | 항목 | 값 |
   |---|---|
   | 설명 | 보강 신청 게시판 (아무 값이나 가능) |
   | 다음 사용자로 실행 | **나** |
   | 액세스 권한이 있는 사용자 | **모든 사용자** |

4. **배포** 를 누릅니다.
5. 처음에는 권한 승인 창이 뜹니다. → 계정 선택 → *고급* → *(안전하지 않음)으로 이동* → **허용**
   (본인이 만든 스크립트라면 정상적인 경고입니다.)
6. **웹 앱 URL** 을 복사합니다. 반드시 **`/exec` 로 끝나는** 주소여야 합니다.

   ```
   https://script.google.com/macros/s/AKfycb..... /exec
   ```

## 4. 홈페이지에 주소 넣기

`index.html` 의 아래 부분에 3단계에서 복사한 주소를 붙여 넣습니다.

```js
const MAKEUP_API = '';   // ← 따옴표 안에 /exec 주소를 붙여넣기
```

그다음 커밋 후 push 하면 홈페이지에 반영됩니다.

```bash
git add index.html
git commit -m "보강 신청 게시판 Google 시트 연동"
git push
```

---

## 확인 방법

- 홈페이지 → **보강 신청** 탭 → 신청서 작성 → **신청하기**
- 스프레드시트의 `보강신청` 시트에 한 줄이 추가되면 정상입니다.
- `MAKEUP_API` 가 비어 있으면 화면 위에 "이 브라우저에만 저장됩니다" 안내가 표시되고,
  목록도 그 브라우저에서만 보입니다.

## 코드를 수정했을 때

`Code.gs` 를 고친 뒤에는 **배포 → 배포 관리 → 수정(연필) → 버전: 새 버전 → 배포** 를 다시 해야
홈페이지에 반영됩니다. (주소는 그대로입니다.)

## 참고

- 수집 항목: 강사명, 학교, 학생(대상), 원래 수업일·시간, 보강 날짜·시간, 사유
  — 개인정보를 최소한으로만 적도록 안내해 주세요.
- 시트를 공유할 때는 **특정 사용자에게만** 공유하고, 웹에는 "모든 사용자"로 배포하는 것이 일반적입니다.
  (웹 앱은 `doPost` 접수와 `doGet` 목록 조회만 허용합니다.)
- 날짜·시간 열(E~H)은 시트에서 자동으로 날짜로 바뀌지 않도록 **텍스트 서식**으로 고정되어 있습니다.
